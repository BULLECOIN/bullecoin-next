BULLE v7 — Bull Runner 2.0 + Community Spotlight

New:
- Share score on X
- Free beta / Energy Cells preview
- Community visual section
- X and Telegram links
- Responsive styles

Install:
1. Stop server.
2. Replace app, components, public and tsconfig.json.
3. Run:
   cd ~/bullecoin
   rm -rf .next
   npm run build
   npm run dev
4. Publish:
   git add .
   git commit -m "Add Bull Runner 2.0 and community spotlight"
   git push

Important: the leaderboard remains local. Real prizes require a global database,
server-side validation, anti-cheat review and official competition rules.
