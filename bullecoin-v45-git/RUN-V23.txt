BULLECOIN ARENA V23 — MAC

1. Unzip the package in Downloads.
2. Open Terminal.
3. Type: cd 
4. Drag the BULLE-V23-Market-News-Trends folder into Terminal and press Enter.
5. Run: npm install
6. Run: npm run dev
7. Open in Safari or Chrome: http://localhost:3000/bull-runner

IMPORTANT
- Do not type the folder path by itself. The command must begin with cd and a space.
- If port 3000 is busy, Terminal will show another address, usually http://localhost:3001.
- Game progress is stored locally in the browser.
- Music starts only after pressing the SOUND or MUSIC button because browsers block automatic audio.
